# Análise Estatística de Consumo de Água | Statistical Analysis of Water Consumption

## 🇧🇷 Português

### Sobre o projeto

Projeto de análise estatística de dados diários de consumo de água usando a linguagem R. O objetivo é aplicar estatística descritiva, identificar valores atípicos e visualizar padrões de consumo.

Os dados utilizados são simulados para fins educacionais e não representam medições reais.

### Tecnologias

- R
- Estatística descritiva
- Manipulação e validação de dados
- Visualização de dados
- Exportação de relatórios CSV e TXT

### Indicadores analisados

- Consumo total e média diária
- Mediana e desvio-padrão
- Valores mínimo e máximo
- Amplitude e quartis
- Coeficiente de variação
- Valores atípicos pelo método IQR
- Média diária por mês

### Como executar

1. Instale o R ou o RStudio.
2. Abra a pasta do projeto.
3. Execute `src/analise_consumo.R`.
4. Consulte os relatórios e gráficos gerados na pasta `outputs/`.

### Estrutura

- `data/`: conjunto de dados CSV.
- `src/`: código-fonte em R.
- `outputs/`: tabelas e relatórios.
- `outputs/graficos/`: gráficos estatísticos.

## 🇺🇸 English

### Project overview

A statistical analysis of daily water consumption using the R programming language. The project applies descriptive statistics, identifies potential outliers, and visualizes consumption patterns.

The dataset is simulated for educational purposes and does not represent real measurements.

### Technologies

- R
- Descriptive statistics
- Data validation and processing
- Data visualization
- CSV and TXT report generation

### Analyzed metrics

- Total and average daily consumption
- Median and standard deviation
- Minimum and maximum values
- Range and quartiles
- Coefficient of variation
- Potential outliers using the IQR method
- Monthly average daily consumption

### How to run

1. Install R or RStudio.
2. Open the project folder.
3. Run `src/analise_consumo.R`.
4. Review the generated reports and charts in the `outputs/` folder.

### Project structure

- `data/`: CSV dataset.
- `src/`: R source code.
- `outputs/`: tables and reports.
- `outputs/graficos/`: statistical charts.

### Disclaimer

This project is intended for educational and portfolio purposes. Statistical outliers should be investigated and do not necessarily indicate measurement errors.
